🏗️ Architecture Deep Dives
Technical details of each detector design.
🌐

SpatialDetector

EfficientNet-B0 · Trained & Audited ✅

  • timm EfficientNet-B0 backbone (pretrained ImageNet)
  • Head: Dropout → Linear(1280→256) → BN → SiLU → Linear(256→1)
  • Xavier uniform init; configurable backbone freeze stages
  • Equalized-odds regularised BCE (λ = 0.5)
  • WeightedRandomSampler over 20 MST × Gender subgroups
  • Grad-CAM XAI on last Conv2d layer
  • Input: 224×224 RGB, ImageNet normalisation
  • 3 epochs · batch 64 · AdamW lr=1e-4
Best single-stream — fully evaluated
📡

FrequencyDetector

ResNet-34 + 2D-FFT · Benchmark estimate

  • FrequencyExtractor: log-magnitude + high-pass residual → 6ch
  • torch.fft.fft2 → fftshift → log(1+|FFT|) per-channel normalised
  • High-pass radial mask, cutoff = 0.1 (normalised freq units)
  • ResNet-34 backbone with in_chans=6 (adapted first conv)
  • Same head as SpatialDetector
  • Fully differentiable — FFT computed in forward pass
  • Detects GAN upsampling spectral grid artefacts
Best for periodic synthesis artefacts
🔀

DualStreamDetector

Gated Spatial + Frequency Fusion · Projected Best

  • Parallel spatial (EfficientNet-B0) + frequency (ResNet-34) streams
  • Feature concat: [spatial_feat ‖ freq_feat] (1280 + 512 = 1792-dim)
  • Gated fusion: σ(Linear(1792→1792)) × fused — learned channel attention
  • Shared fusion head: Dropout → 256 → BN → SiLU → 1
  • extract_features() bypasses each stream's head
  • Both streams share equalized-odds training objective
  • Run benchmark.py to reproduce full comparison
Projected best overall fairness + performance

Reproduce this benchmark: Run python benchmark.py from the project root to train all four configurations (EfficientNet-B0 Spatial, ResNet-50 Spatial, ResNet-18 Frequency, EfficientNet-B0 DualStream) and generate benchmark_results/benchmark_report.md and CSV comparison. Expect ~6 hours on a 12-core CPU machine.
