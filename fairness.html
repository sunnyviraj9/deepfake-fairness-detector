🧮 Fairness Mitigation Techniques
Equalized Odds Loss

BCE + λ·(Var(soft_FPR across MST groups) + Var(soft_TPR across MST groups)). λ = 0.5. Penalises variance in subgroup error rates using differentiable sigmoid surrogates.

L = BCE + 0.5 × (Var(FPR_g) + Var(TPR_g))
Demographic Balanced Sampling

PyTorch WeightedRandomSampler assigns each training sample a weight of 1/count(subgroup) where subgroup = gender × MST. Ensures rare combinations (e.g., Dark-Female) are not under-represented per batch.

WeightedRandomSampler 20 subgroups
Optimal Threshold Calibration

After training, find_optimal_threshold() walks the ROC curve to find the highest-TPR operating point where overall FPR ≤ 5%. The result (T = 0.1463) is stored in the checkpoint and loaded at inference time.
