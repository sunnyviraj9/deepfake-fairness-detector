🧠 How Neural Inference Works

The trained EfficientNet-B0 model is exported to ONNX and loaded via ONNX Runtime Web (WebAssembly) entirely in your browser. Same model: AUC 0.9987 on 5,000 test images. Preprocessing: resize 224×224, ImageNet normalisation, CHW Float32Array. Output: raw logit → sigmoid → threshold 0.1463.
