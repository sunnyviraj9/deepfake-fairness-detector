SpatialDetector

EfficientNet-B0 · Trained & Audited ✅

  • timm EfficientNet-B0 backbone (pretrained ImageNet)
  • Head: Dropout → Linear(1280→256) → BN → SiLU → Linear(256→1)
  • Xavier uniform init; configurable backbone freeze stages
  • Equalized-odds regularised BCE (λ = 0.5)
  • WeightedRandomSampler over MST × Gender subgroups
  • Grad-CAM XAI on last Conv2d layer
Best single-stream result — fully evaluated
📡

FrequencyDetector

ResNet-34 + 2D-FFT · Benchmark estimate

  • 2D FFT log-magnitude + high-pass spatial residual → 6-ch tensor
  • ResNet-34 backbone with in_chans=6
  • High-pass cutoff radius: 0.1 (normalised frequency units)
  • Detects GAN upsampling spectral grid artefacts
  • Fully differentiable via torch.fft.fft2
  • Complementary to spatial features
Best for GAN / periodic synthesis artefacts
🔀

DualStreamDetector

Gated Spatial + Frequency Fusion · Projected Best

  • Spatial & Frequency streams process input in parallel
  • Feature concat: [spatial_feat ‖ freq_feat]
  • Gated fusion: σ(Linear(fused)) × fused — learned attention
  • Shared head: Dropout → 256 → BN → SiLU → 1 logit
  • Projected lowest F_EO via combined domain evidence
  • Run benchmark.py to reproduce full comparison
Projected best overall fairness + performance
